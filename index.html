Tide Coefficient Prediction using Random Forests

A machine learning project leveraging environmental and temporal data to predict tide coefficients using ensemble learning methods.

View on GitHub Explore Results

Project Overview

This project explores the use of Random Forest regression to model and predict tide coefficients based on historical and astronomical features such as time, lunar cycle, and environmental conditions.

Methodology

  • Data collection and cleaning
  • Feature engineering (time-based and astronomical variables)
  • Training a Random Forest Regressor
  • Model evaluation (MAE, RMSE)
